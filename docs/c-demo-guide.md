# C 角色演示与视觉走查

## 三分钟演示顺序

1. 打开首页，确认主输入区、链接/短信切换和示例入口完整可见。
2. 选择“银行认证”示例并开始研判，展示页面直接进入 `/analyze` 并自动运行。
3. 观察六个阶段依次推进，强调进度来自 `/api/analyze` 的服务端流事件，而不是前端定时模拟。
4. 滚动到证据链，依次展示输入规范化、RAG 检索、置信度、沙箱行为、综合研判和结论。
5. 在沙箱节点展示模板模拟页面快照、跳转链、表单字段、脚本行为、IOC、数据来源和响应耗时。
6. 展示结论卡的诈骗等级、置信度、处置建议和 Tier0 离线模板标识。
7. 打开历史记录，点击“回放”，确认载入同一份证据链快照。
8. 演示纯短信样例，说明没有链接时不会生成虚假的页面、跳转或表单证据。

## 推荐演示话术

- “在线时优先使用 urlscan.io 与 VirusTotal；演示保留域名会被主动跳过，系统自动切换到 Tier0。”
- “Tier0 是内置行为模板，界面会明确标注为离线模板，不冒充真实在线扫描。”
- “离线截图由 Tier0 模板生成，图片和界面都会标注为非真实页面访问。”
- “即使断网或额度耗尽，仍能完整展示从输入到结论的证据链。”
- “可疑 URL 只在服务端处理，前端不提供可点击跳转。”

## 视觉走查

- 桌面 1536x1000 下无横向溢出，阶段面板与证据链对齐。
- 390px 宽度下无横向溢出，底部导航不遮挡末段内容。
- 沙箱证据卡中的长 URL 使用省略或换行处理，不撑破容器。
- 错误状态、空状态、加载状态和回放状态均可辨识。
- 减少动态效果偏好开启后，动画不会影响信息读取。
